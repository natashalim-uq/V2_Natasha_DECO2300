This is my DECO2300 project repository. The Unity project lives in the `FINALFINALVR/` folder.

## A note on the repository history (and the names)

This project has ended up spread across three repositories, so here is what happened:

1. **[Natasha_DECO2300_2026](https://github.com/natashalim-uq/Natasha_DECO2300_2026/tree/main)** was my original repository. About a week after Interactive Prototype 1 (IP1) my files stopped opening, and even with my tutor's help we couldn't get them working again.
2. **Natasha_DECO2300_2026_redo** was created with my tutor's help as a second attempt. Unfortunately, a few days later its files stopped opening as well. This one was only ever kept locally on my laptop and never pushed to GitHub, because its `.gitignore` wasn't working and it would have uploaded far too many files. Its contents are now on the [`old-repo-archive`](../../tree/old-repo-archive) branch of this repository instead.
3. **V2_Natasha_DECO2300** (this repository) is where I restarted the project from scratch, and it is the one that contains my current, working project.

I'm sorry about the confusing naming of the repositories and folders (including `FINALFINALVR`). I've kept the names as they are because renaming them now could break file paths and references inside the Unity project.
